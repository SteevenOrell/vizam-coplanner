# Co-planner design references (Steeven posted them in the LumaPath session, 2026-11-11)

Steeven sent 4 images to the LumaPath session: 2 for e-learning (handled there) and 2 for the "co planner".
The images live only in that chat; this is a written description. Ask Steeven to re-attach them to the co-planner
session if the exact pixels are needed.

## Ref A — "Finora" banking app (dark blue)
- Two iPhone mockups on a deep royal-blue to navy gradient, huge pale wordmark behind them.
- Dark navy UI (#0f1630-ish) with bright blue (#3b7cf5-ish) accents, light text.
- Home: avatar + "Hello <name>!" + bell; big balance number with lighter decimals; horizontal carousel of glassy
  blue gradient cards; "Quick Actions" grid of 8 outline icons in a rounded dark panel; "Last Transactions" list;
  bottom tab bar (Home, Card, Transfer…).
- Card screen: large frosted glass card, "Card Control" row of 4 round blue icon buttons with labels, two stat tiles
  ("This Month Uses $1,800 / 3,600") with blue-to-lime progress bars and a % pill.

## Ref B — "Payno" banking app (light silver)
- Three iPhones on pale grey concrete, faint giant wordmark, very light grey/white UI with navy (#2f3f6b-ish) accents.
- Onboarding: step indicator "1/4", large thin headline "Banking Made Simple", stacked white rounded cards, Skip/Next pills.
- Home: "Welcome Back" + name + avatar, balance card with eye toggle, quick actions as round outline buttons
  (Send, Add Funds, Pay Bills), recent list with avatars, bottom bar with a raised round navy "+" centre button.
- Transfer: back + title + bell, recent recipients avatars row with "Add New", amount fields with currency pills,
  payment method tiles grid, summary card. Soft gradients, generous radius (~20px), thin type.
